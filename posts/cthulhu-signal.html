来自深渊的信号

2026-11-14 小说 克苏鲁 DEEP.SIGNAL // 观测记录 №014

先说结论：本站昨晚收到一段不该存在的信号。以下内容整理自当值记录，部分段落建议不要在深夜阅读——当然，你现在已经这么做了。

> FILE: OBS-2026-1114-039 // STATUS: 待归档 // SAN 状态: 尚可

异常频谱 // 0:39

昨晚例行巡检，一切正常。0 点 39 分，频谱图的底噪里突然立起一座尖峰——频率落在一个不存在任何已知电台的区间，脉动间隔极不规律，像某种缓慢的呼吸。

第一反应：设备故障。第二反应：邻居的微波炉。第三反应出现的时候，我已经把录音挂上了解调器。

信号有个很奇怪的特点：它不在「播放」，它在「等待」。你把音量调到最小，它还在那里；调到最大，它并没有变得更响——只是感觉它离你更近了。

转写记录 // 不可名状的部分

解调出的文本残片如下（转写自脉冲间隔，原「文」并非任何已知语言，以下为意译尝试，语义完整度存疑）：

> ……那不是噪声。它在呼吸。
> ……沉没的城并不沉默。石阶上长满温柔的触手，
> 像欢迎归乡者一样，缠绕每一位观测者。
> ……它梦着。它在它的家里，在拉莱耶，
> 等待着，梦着。
> ——不要唤醒它。但也请不要挂断。

「拉莱耶（R'lyeh）」这个词出现了三次。我对着一个不存在的电台，听见了海底城市的地址。

交叉比对 // 一位名叫洛夫克拉夫特的前辈

顺着「拉莱耶」检索，交叉比对结果指向一位前辈观测者： Howard Phillips Lovecraft，美国人，1890–1937，职业作家，业余天文学家，长期记录「来自人类历史之外的低语」。

他比我早了一百年收到同样的信号，并且干了一件非常大胆的事：他把信号全部转写、整理、公开发表，统称为——克苏鲁神话（Cthulhu Mythos）。

也就是说，这个频率对全人类广播已经一个世纪了，而大部分人的接收器一直没有调对频道。

克苏鲁神话速览 // 给新调查员的简报

用一分钟讲清楚这套体系为什么迷人：

传统恐怖故事里，人类是主角，怪物再强也会被打败，宇宙最终站在我们这边。克苏鲁神话把这个前提整个抽掉了——宇宙对人类毫无兴趣，我们只是恰好醒着的尘埃。那些「神」并非恶意，只是庞大：就像你走路时不会注意到脚下的蚂蚁城邦，它们「路过」一下，文明就会重新洗牌。

克苏鲁（Cthulhu）是其中最著名的一位：章鱼头、蝠翼、山一样大的身躯，沉睡在太平洋海底的拉莱耶城。它不是在等你，它只是在睡。而「世界还存在着」这件事，仅仅因为它还没醒。

这种恐怖有个专有名词：宇宙恐怖（Cosmic Horror）。怕的不是被吃掉，是「意义」本身被放大镜照出的渺小。

调查员入门包 // SAN 值保管指南

如果你想亲自接收这个频率，从下面任意一个入口潜入均可：

纸面入口：洛夫克拉夫特短篇《克苏鲁的呼唤》（1926，与本站收到信号的年代惊人一致）和《疯狂山脉》。篇幅短，后劲长，SAN 消耗适中。

游戏入口：《克苏鲁的呼唤（Call of Cthulhu）》或《沉没之城》——扮演调查员，亲眼验证「知道得越多，SAN 掉得越快」这条铁律。

跑团入口（强烈推荐）：COC（克苏鲁的呼唤）TRPG。几包骰子、一张角色卡、一位守秘人（KP），以及愿意一起发疯的朋友。核心机制非常哲学：你的理智是资源，求知是消耗——每读懂一份禁忌文献，都要掷骰子扣 SAN。

这份「越聪明越痛苦」的设定，在我看来是对好奇心最浪漫的致敬。

结案与守则

本次观测的最终结论如下：

1. 信号源至今仍在待机，未再升级为「通话」。
2. 本站已制定三项守则：不回复、不录制完整频率、不向任何人转播原文。
3. 但观测记录必须共享——独自知道这种事，SAN 掉得更快。

所以这份文件才会出现在你面前。

如果你也曾在某个深夜的频谱图上见过类似的尖峰，或者已经在《克苏鲁的呼唤》跑团里失去过多半条理智条——评论区在下面，观测记录欢迎互相比对。

毕竟，SAN 值这种东西，就是要一起掉，才掉得快乐。
