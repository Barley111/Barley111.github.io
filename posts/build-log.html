信号站搭建记录 —— 一个人也能点亮一座基站

2026-11-11 技术 阅读约 5 分钟

这篇文章记录信号站 v1.0 的搭建过程：目标、选型、设计笔记和上线路线。写给它自己，也写给未来想改版的自己。

一、需求清单

  • 别人在浏览器里点开一个链接就能看，不需要注册、不需要装 App；
  • 免费托管，最好不花一分钱；
  • 离线可写——网络再抽风，也不影响本地写作和预览；
  • 加载要快，没有乱七八糟的依赖；
  • 外观要有辨识度，不能像模板站。

二、选型：为什么是纯手写静态页

主流方案有三条路：

  • WordPress 之类——功能全，但需要服务器和数据库，维护成本高，杀鸡用牛刀；
  • Hexo / Hugo 静态生成器——写 Markdown 很舒服，但要装依赖、挑主题、学配置，而且好主题基本都躺在 GitHub 上（本次恰好连不上）；
  • 纯手写 HTML + CSS + 少量 JS——零依赖、零构建、完全可控。写新文章就是复制一个模板文件。
对个人博客来说，「能一直写下去」比「功能齐全」重要得多。所以我选了最不会坏的那条路：直接写 HTML。

反正以后随时可以迁移到 Hexo/Hugo——静态页面的好处就是搬到哪都能用。

三、设计笔记

视觉方向定为「明日方舟式终端 UI × 初音未来配色」：

  • 深色控制台底色 + 微弱的网格与扫描线，营造「基站机房」氛围；
  • 主色取初音未来的代表色 #39C5BB（葱绿），辅以少量琥珀黄做警示点缀；
  • 面板采用斜切角（clip-path）和倾斜的导航按钮，来自明日方舟 UI 的经典语言；
  • 状态栏、HUD 芯片、等宽字体，让页面看起来像一台正在运行的设备；
  • 首页的打字机光标和心跳灯，是这座基站的「生命体征」。
:root {
  --teal: #39c5bb;   /* 初音绿：主色 */
  --bg: #0a0e13;     /* 机房深空底色 */
  --yellow: #f0c75e; /* 琥珀黄：警示点缀 */
}

四、目录结构

├── index.html          首页（文章列表）
├── about.html          关于页（站长档案）
├── posts/              文章目录
│   ├── hello-world.html
│   ├── build-log.html  ← 你正在看这篇
│   └── TEMPLATE.html   新文章模板
└── assets/
    ├── css/style.css   设计系统
    └── js/main.js      打字机 / 统计 / 动画

五、上线路线

托管选 GitHub Pages：免费、稳定、直链可访问。步骤概要：

  1. 在 GitHub 新建仓库 用户名.github.io；
  2. 把这个文件夹里的所有文件推上去；
  3. 打开仓库 Settings → Pages，选择 main 分支；
  4. 等一两分钟，https://用户名.github.io 就是这座信号站的公开地址。

完整命令和「连不上 GitHub 怎么办」的排查手册，都写在项目的 README.md 里。
